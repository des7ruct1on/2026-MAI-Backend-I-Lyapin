# Lesson 01 — LRU Cache

## Что сделано
- Реализован `LRUCache` с операциями `get/set/rem` за O(1) за счёт:
  - хэш-таблицы `dict[key -> node]`
  - двусвязного списка для порядка LRU.
- Добавлен `main.py` с проверкой из условия.

## Требования из задания
- Класс `LRUCache` с методами: `__init__(capacity)`, `get(key)`, `set(key, value)`, `rem(key)`
- Все операции должны работать за **O(1)**
- При отсутствии ключа `get()` должен возвращать пустую строку `""`

## Файлы
- `cache.py` — реализация `LRUCache`
- `main.py` — быстрый smoke-test

## Как устроено (кратко)
- **Словарь** `dict[str, node]` даёт O(1) доступ к элементу по ключу.
- **Двусвязный список** хранит порядок использования:
  - голова = “самый недавно использованный”
  - хвост = “самый давно использованный”
- При `get/set` элемент “поднимается” к голове.
- При переполнении ёмкости удаляется узел перед хвостом (LRU).
